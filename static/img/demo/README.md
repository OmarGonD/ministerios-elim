# Imágenes de demostración

Estas imágenes se generan una sola vez y se versionan con el proyecto. Los
comandos `seed_demo` y `demo_seed` las importan a Wagtail; no requieren acceso
a internet ni generación durante la carga.

El logo del sitio permanece en `static/img/logo-elim.png` y no se reemplaza.

## Prompts
